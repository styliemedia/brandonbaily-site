# brandonbaily.co.uk

Personal site for Brandon Baily: stunt rider, arena MC, photographer and web builder.

Plain HTML, CSS and JavaScript, no build step. Hosted on Cloudflare Pages, which redeploys whenever `main` changes.

- `index.html`: page content (look for the `EDIT` and `To show real posts` comments)
- `styles.css`: design (colours are at the top)
- `assets/`: put photos here, e.g. `assets/hero.jpg` for the top banner
