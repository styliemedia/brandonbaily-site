# brandonbaily.co.uk

Personal site for Brandon Baily: arena MC and stunt rider.

Plain HTML, CSS and JavaScript, no build step. Hosted on Cloudflare, which redeploys whenever `main` changes.

- `index.html`: page content. Tour dates are `<li class="date">` blocks; past dates move to "Earlier this year" automatically.
- `styles.css`: design (colours and fonts are at the top)
- `script.js`: tour-date sorting and the photo lightbox
- `assets/hero.jpg`: main photo
- `assets/photos/`: gallery photos
- `assets/about.mp4`: portrait video for the About section
